# SCL v0.3+ 需求头脑风暴（草案 · 待圈选）

- 日期：2026-09-07　状态：**已圈选 v0.3 范围（P0 五项 + 交互终端提前），实施计划见 v03-plan.md**
- 约束（用户原话）：
  1. **可裁剪**（每个功能都要有开关，且能裁剪）
  2. **功能可靠、覆盖常用场景**（覆盖 = 也要能裁）
  3. **对比市面脚本**（没必要全加，只取合理子集）
  4. **参考终端库**（历史、补全…）
  5. **小而美**（默认最小档，要什么开什么）

---

## 0. 现状基线（v0.2，2026-09-07 已提交 + tag）

运行时：文本→字节码（4B/指令）；label/jump；类型化参数字节缓存（bool/int/flag/string）；
类型化变量 `var <type> x=v`；内置 int/bool 运算指令（iadd…btest，保留字）；`${x}`；
`G_RETURN` 条件 + 读后清零；异步 sync；help/free；静态内存、无 malloc/OS/libc。
S2C：现代语法 → label/jump 汇编（var 类型推断、原子条件、单运算符算术赋值、fn 编译期内联、
if/else、while do-while、ret 糖）。测试 scl_test=59 / s2c_test=38 全绿。

对照地看，现在的“短板/机会”：
- 条件表达式只到“原子”，无 `&& ||`、多运算符、括号、for、break/continue；
- 无位运算/移位/hex 字面量（寄存器场景常用）；
- 无“防死循环”保护（jump 无限跑，只能外部 Abort）；
- 没有“交互终端”形态（历史/补全/行编辑）—— 目前只做“整条链下发”；
- 配置只有单份默认，无“最小档/全功能档”模板与内存预算清单。

## 1. 对标（为什么要这些、不追什么）

| 对标物 | 借鉴 | 不借鉴 |
|---|---|---|
| POSIX shell | 变量/流程/注释/（部分）语法直觉 | 管道、重定向、后台、通配（重且与“链”模型不符） |
| Lua / MicroPython / JerryScript | 表达式、多类型 | VM + GC + 宿主对象模型（体积大，违背小而美） |
| 嵌入式 shell（letter-shell、armink、NanoShell 等） | **命令表/历史/补全/行编辑/参数化**（第 4 点来源） | 各自为政的会话层，全部照搬 |
| 指令脚本（PicoShell/TinyShell） | 循环/变量/（部分）算术 | 语法膨胀 |
| 本库哲学 | 保持“指令链数组 + 轻解释”，重活交给 S2C/宿主 | 运行时大 VM |

> 取舍原则：**“链执行能力”进核心（可裁剪），“交互会话能力”放示例/扩展层（整层可裁）**，
> “现代语法糖”留在 S2C（零 RAM 成本）。

## 2. 候选清单（每项带 裁剪开关 / 成本 / 优先级）

### T1 运行时语言/可靠性（库内，全部 `#ifndef` 可裁）

| 编号 | 候选 | 说明 | 裁剪开关建议 | ROM/RAM 成本 | 优先级 |
|---|---|---|---|---|---|
| A1 | **循环/步进上限保护** | 每脚本最大执行步数（防 while(true) 死锁），到限自动 abort 并报错 | `SCL_CFG_STEP_LIMIT`（0=关，默认 e.g. 100000） | 极低 | **P0** |
| A2 | **int 位运算/移位** | `iand ior ixor inot shl shr`（与 bool 的 band/bor 区分开）；S2C 映射 `& \| ^ ~ << >>` | 并入保留字表，或 `SCL_CFG_BITOP_EN` | 低 | **P0** |
| A3 | **hex/进制字面量** | 参数/var 支持 `0x1F`、`0b101`，S2C 同 | 并入解析器（低成本常开） | 低 | **P0** |
| A4 | 字符串比较/长度助手 | `s_eq a b`→G_RETURN（让 S2C 里 string 的 `==` 可用）；`s_len x` 之类 | `SCL_CFG_STROP_EN` | 低 | P1 |
| A5 | 运行时注释 | 链内 `; cmd # 注释`（解析遇 `#` 跳段） | 常开/可裁 | 低 | P1 |
| A6 | 数组（int 小数组） | `var arr[8]` + 下标读/写（多 IO 值/查表常用） | `SCL_CFG_ARR_MAX`(0=关) | 中（索引寻址 opcode） | P2 |
| A7 | 运行时子程序 call/ret | 栈式跳转复用代码段 | `SCL_CFG_CALL_EN` | 中（栈 + opcode） | P2（价值低，S2C fn 内联已覆盖多数） |
| A8 | 无符号/更宽类型 | 一般用 int 足够 | — | — | 不做 |

### T2 S2C 现代语法（Python 层，纯体验，几乎零运行时成本）

| 编号 | 候选 | 说明 | 优先级 |
|---|---|---|---|
| B1 | **完整条件表达式**：`&& \|\| !`、括号、优先级 | 用“短路 label/jump 降级”避免中间临时变量（省槽位） | **P0** |
| B2 | **for(init;cond;step)** | 降到 label + while 模式 | **P0** |
| B3 | **break / continue** | 编译期跳到循环标签（无需新 opcode） | **P0** |
| B4 | **多运算符算术** `a+b*c`（此前报 v0.3） | 需要临时/复用变量；与 B1 一起做表达式提升 | P0/P1 |
| B5 | `switch/case` | 降到 if 链 | P1 |
| B6 | `#include` / 常量 `#define` | 预处理拼接（PC 端脚本库友好） | P1 |
| B7 | 转义 `\n` 等 / do-while 关键字 | 体验优化 | P2 |

### T3 交互终端 / Shell（历史·补全·行编辑 —— 第 4 点；放扩展层整层可裁）

设计成**独立可选模块**（不污染核心库），核心只提供：命令链表可枚举、`help`、`SCL_Abort`。

| 编号 | 候选 | 说明 | 开关建议 | 优先级 |
|---|---|---|---|---|
| C1 | REPL/单行执行 | 提示符 + 读一行当链跑（复用 SCL_Run），Ctrl+C 中断 | `SCL_EX_SHELL_EN` | P1 |
| C2 | 行编辑 | 退格/方向/Home/End/清行（PC 与串口两后端） | `SCL_EX_LINE_EN` | P1 |
| C3 | **历史** | 上下箭头取历史（环形缓冲），行内即时执行“单条命令历史”亦可 | `SCL_EX_HIST_EN/HIST_MAX` | P1 |
| C4 | **补全** | Tab：命令名/保留字/${变量} 前缀匹配（复用命令链表，无需额外注册） | `SCL_EX_COMPL_EN` | P1 |
| C5 | 读字符移植点 | 新增可选 `SCL_Port_GetChar` 轮询接口（或置于扩展层避免强迫核心） | 扩展层 | P1 |
| C6 | 单条命令=指令链 | 交互输入 `var int x=1; iadd x 1 x` 也按链跑 | 复用 | 默认 |

> 与“链脚本”不同目标：链 = 离线批量；shell = 在线人机。二者都吃同一套命令表与执行器，天然一致。

### T4 移植/裁剪体系/工具（第 1、2 点）

| 编号 | 候选 | 说明 | 优先级 |
|---|---|---|---|
| D1 | **裁剪配置档模板** | `scl_cfg_min.h`（默认最小 RAM）与 `scl_cfg_full.h`（全开）两档 + 内存预算表 | **P0** |
| D2 | **MCU 移植示例** | 一个真单片机移植（UART 轮询输入 + 输出）+ 对应 shell 演示 | P1 |
| D3 | 单元测试随功能扩充 | 运算/位/hex/循环保护/表达式 新用例；错误路径 | P0（随功能） |
| D4 | 尺寸/速度报告脚本 | 一键 `gcc size` 多配置对比报告 | P1 |
| D5 | 更细返回码 | `SCL_Run` 区分“编译错/超长/忙碌/为空” | P2 |

## 3. 推荐路线（“小而美”把关）

**v0.3（建议本轮）—— 都是 P0，回报高、彼此相关**
- B1 完整条件表达式（含 B4 多运算符算术，一次性做表达式引擎）
- B2 `for` + B3 `break/continue`（纯编译期 label 降级，零运行时）
- A2 位运算/移位 + A3 hex 字面量（运行时轻指令 + S2C 运算符）
- A1 循环/步进保护（可靠性底线）
- D1 裁剪配置档模板 + 内存预算表（落实“可裁剪”承诺）

**v0.3b / 后续 —— P1**
- T3 交互终端：REPL + 行编辑 + 历史 + 补全（example 扩展层，`SCL_EX_*_EN`）
- D2 一个 MCU 移植示例（附最小档配置）
- A4 字符串比较 / A5 链内注释 / B5 switch / B6 include

**更后面 —— P2**
- A6 小数组、B7 转义、D5 返回码、D4 报告脚本

**明确不做**：运行时 VM+GC、真函数调用栈、管道/后台/通配、浮点数学、多字节 UTF-8 会话——性价比低，违背小而美。

## 4. 内存预算口径（草案）

- 核心默认档（全部新功能 OFF）≈ v0.2 体积 + 仅“循环保护”加几字节；
- 全功能档：A1–A3 + 编译产物缓冲按需上调；
- shell 扩展层独立核算（历史缓冲按 `HIST_MAX × 行长`，随例外挂）。
- 每次合入前跑尺寸报告脚本，超预算预警。
